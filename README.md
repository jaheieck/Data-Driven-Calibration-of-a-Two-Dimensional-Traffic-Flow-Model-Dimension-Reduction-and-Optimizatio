# Data-Driven Calibration of a Two-Dimensional Traffic Flow Model: Dimension Reduction and Optimization Strategies
This contains all material for the publication: "Data-Driven Calibration of a Two-Dimensional Traffic Flow Model: Dimension Reduction and Optimization Strategies"


The 3 folders contain the following data for each of the datasets (On-Off-ramp dataset, highD dataset, Heidelberg sensor dataset):

- folder `images`: contains all used images
- folder `optimzation`: contains all necessary files to apply the different optimization methods
- link `Website`: opens a websites, which describes the data
- Jupyter Notebook `traffic_model_opt_comparison`: contains all numerical simulations for each dataset respectively
- Jupyter Notebook `traffic_model_sensitivity_analysis`: contains the sensitivity analysis for the On-Off-ramp dataset
- Note: Since the data-files are too large to upload here, we refer to the corresponding Websites to access the data.

Each script and function has a short description, what their purpose is.
